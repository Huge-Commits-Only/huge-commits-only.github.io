# 🌐 huge-commits-only.github.io

Strona organizacji [Huge Commits Only](https://github.com/Huge-Commits-Only) na GitHub Pages: statyczny HTML i CSS, bez JavaScriptu, ciasteczek i zewnętrznych zasobów (ścisłe CSP).

Zmiany przez PR jak wszędzie; po scaleniu GitHub Pages publikuje gałąź `main` w ciągu minuty. Grafiki w `assets/` to kopie z repozytoriów projektów — przy nowym demo podmień też tutaj.
